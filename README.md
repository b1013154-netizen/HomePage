# HOSHIZORA

## 全天プラネタリウム

`public/planetarium.html` に追加。左ボタンをホールドしてドラッグ、ホイールでズーム。タッチのスワイプとピンチ、方向キー・＋／−・Homeにも対応します。

- XHIP由来の実在恒星118,216個（d3-celestial stars.14.json）を軽量な配列形式に変換して同梱。最大13.78等。全天のすべての恒星を網羅したカタログではありません。
- WebGLのポイント描画。WebGLが使えない端末ではCanvas 2Dへフォールバック。
- 等級の上限4〜14、星座線・星座名・明るい星名・天球グリッドの切り替え、全88星座への視点移動、星のクリックによるHIP番号・等級・名前の表示。
- 星の座標はJ2000、色はB−Vの補間近似、点の半径と光のにじみは視認性のための表現。観察地・時刻・地平線・惑星・固有運動の計算は行いません。
- 星の元データ：https://github.com/ofrohn/d3-celestial/blob/master/data/stars.14.json
- 星名：https://github.com/ofrohn/d3-celestial/blob/master/data/starnames.json
- 元星表：XHIP, Anderson & Francis (2012), VizieR V/137D。加工元ライセンスは `public/assets/d3-celestial-LICENSE.txt` に同梱。

星座を季節や名前から探せる、日本語のサンプルサイトです。HTML・CSS・JavaScriptのみで動作します。

## 機能

- 国立天文台の公式一覧に照合した全88星座を収録（へび座の頭部・尾部は1星座）
- 季節と北天・南天などのエリアでの絞り込み、名前順・学名順・面積順
- 日本語名・学名・略符・漢字での検索、ひらがな・カタカナの表記ゆれ対応
- 星の座標から投影した配置図、正式略符・学名の属格・面積・20時の位置の目安
- 元の12星座の観察ガイド・神話も継続掲載
- スマートフォン対応、キーボード操作、動きを抑える設定への対応

実際の観察日時の星の位置を計算する星図ではありません。季節区分は国立天文台の東京20時の位置の目安から春4〜6月・夏7〜9月・秋10〜12月・冬1〜3月に分類しています。北天・天の赤道付近・南天は配置図の中心赤緯が30度以上・±30度未満・マイナス30度以下による分類です。南天の星座には日本から一部・全体が見えないものもあります。

## CHARACTER FORGE / ゲーム用キャラメーカー

`/character` に追加。数値の合計（6〜9,999）を整数で6能力へ配分、または入力した6つの整数（1〜9,999・合計9,999以下）をシャッフル。同じ入力・シード・生成器バージョンで同じ結果を生成します。自由入力の職業と性格はキーワードに応じたテンプレートに反映し、未知の職業には汎用設定を使用。新規キャラのイラストは事前制作したアニメ調ポートレートから選びます。利用時の外部生成API料金は不要です。

ファンタジー・現代・SFの設定、完全ランダム・職業に応じた配分、テキストコピー、JSONダウンロード、ブラウザへの最大20体保存に対応。保存データは端末のlocalStorageのみで、同期・アカウント・サーバー保存はありません。独自の能力値とスキルであり、特定のゲームのバランスは保証しません。


### キャラメーカー v2.0

味方・敵・モブ・国民（おまかせ可）の立場と、戦闘／非戦闘の指定を追加。合計上限9,999。性格32候補、通り名の組み合わせ、戦闘系12種・生活系12種の能力プールから通常スキル2つと重複しないユニークスキルを選びます。制約、武器／職業に応じた特技、所属、年齢、性格の裏側、生育環境、生い立ち、転機、人としての強みと弱み、口癖、出会い、関係の変化、目的、外見、好き嫌い、秘密、イベントの種を生成。追加項目はテキスト・JSON・ローカル保存にも含みます。

v1の保存先を継続使用し、旧データは保存時の内容を保持して表示します。旧版を再生成する場合はv2のルールに変わる旨を画面に表示します。同じ結果の再現は、同じ入力・シード・生成版の組み合わせで保証します。


### キャラメーカー v3.0

- 世界観12種：王道ファンタジー、現代・異能、SF・宇宙、和風・妖怪譚、中華幻想・武侠、スチームパンク、サイバーパンク、ゴシック・怪奇、終末・サバイバル、神話・古代文明、魔法学園、海洋・空島冒険。追加世界の背景・所属・出会う場所・武器も専用データを用意。
- 各世界30職業（戦闘10・専門10・生活10）。合計360候補、重複を除く職業名357種。検索付きselectと自由入力に対応。分類は世界観の職業カタログを優先。
- 通り名は世界観ごとの語彙、24種の叙述句、12種の接続表現、戦闘／非戦闘各16種の呼称、4つの文型を組み合わせて生成。
- 内蔵image_genで制作したアニメ調ポートレート24種を自動／手動で選択。素材とプロンプトは `docs/character-art-v3.md` を参照。画像を毎回生成する機能ではなく、事前制作した画像の選択です。
- v1/v2の保存内容は保持して表示し、再生成時のみv3ルールに移行。v3の保存・JSONにイラスト番号と素材参照を含む。
